Start a thread in the right project without touching the mouse.

## What you get

- A centered picker on Cmd+N with a search field and your projects, most
  recently active first.
- Arrow keys and Enter, or Cmd+1 to Cmd+9, to pick. Esc closes.
- Picking a project opens BB's new-thread screen for it with the prompt
  focused.

## Setup

BB's own "New thread" command also uses Cmd+N. Disable it, or give either
command another shortcut, in BB's keyboard settings.
